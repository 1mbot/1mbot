## Projects

*Most of my projects are in private repositories, so I'm only sharing summaries here.*

**Smart Buoy for Optical Detection and AI-Based Classification of Microplastics** | *STM32, Optical Sensing, Signal Processing*

- Autonomous, solar-powered buoy for continuous in-situ microplastic monitoring in natural water bodies.
- Designed the optical chamber and photodiode-based sensing, with STM32-based real-time ADC sampling, digital filtering and data logging.
- Won **Best Hardware Project Award** at SPIT Annual Day 2026 and **1st place** in the Main Project Exhibition.

**Blind Person Visual Aid (AI-Based Smart Glasses)** | *YOLOv8, OpenVINO, Raspberry Pi, Computer Vision*

- Assistive smart glasses with real-time object detection, face recognition and audio feedback through a client-server video pipeline.
- Built custom datasets (~54k and ~63k images) and optimized inference with Intel OpenVINO via PyTorch-ONNX-IR conversion.
- Offloaded computation from the Raspberry Pi over TCP sockets while staying near real-time.
- **1st place** at the AI PC Workshop Hackathon, SemiX, IIT Bombay (Sept 2025).
